\# Профессиональный профиль — Саня Агеев



Современная, адаптивная веб-визитка (профиль) для эксперта в области цифровых решений, стратегического консалтинга и управления продуктами. Проект представляет собой одностраничный сайт с отдельными HTML и CSS файлами, выполненный в минималистичном, но премиальном стиле.



!\[Preview](https://via.placeholder.com/800x450?text=Professional+Profile+Sanya+Ageev)



\## 🚀 Особенности



\- \*\*Чистая архитектура:\*\* HTML и CSS разделены по файлам для удобства поддержки.

\- \*\*Адаптивный дизайн:\*\* Корректно отображается на всех устройствах (десктопы, планшеты, смартфоны).

\- \*\*Современный визуал:\*\* Тонкие градиенты, фоновые «орбы», паттерн-сетка, стеклянная морфная карточка (glassmorphism в шапке).

\- \*\*Интерактивность:\*\* Приятные hover-эффекты на кнопках, карточках, иконках и ссылках.

\- \*\*Структурированный контент:\*\*

&#x20; - Шапка с аватаром, контактными данными и статусом.

&#x20; - Биография / короткое резюме.

&#x20; - Хронология карьерного трека (timeline).

&#x20; - Образование и сертификаты.

&#x20; - Навыки и экспертиза (теги).

&#x20; - Ключевые достижения в цифрах.

&#x20; - Блок контактов и соцсетей.

&#x20; - Языки с уровнем владения.

&#x20; - Отзыв / рекомендация.

&#x20; - Футер с информацией.

\## 🛠 Используемые технологии



\- \*\*HTML5\*\* — семантическая разметка, современные теги.

\- \*\*CSS3\*\* — CSS Grid, Flexbox, кастомные свойства, медиазапросы, transition.

\- \*\*Google Fonts\*\* — шрифты \*Inter\* (основной) и \*Space Grotesk\* (акценты).

\- \*\*Font Awesome 6\*\* (CDN) — иконки для контактов, секций, соцсетей.

\- \*\*Кастомные фоновые элементы\*\* — декоративные размытые круги и паттерн.



\## 📥 Установка и запуск



Для работы достаточно любого современного браузера. Весь проект работает локально без сервера.



\### 1. Клонирование или скачивание



```bash

git clone https://github.com/your-username/professional-profile.git

Или просто скачайте ZIP-архив и распакуйте.



2\. Структура файлов

Убедитесь, что index.html и style.css находятся в одной папке.



3\. Открытие

Дважды кликните на файл index.html или перетащите его в окно браузера.



🔹 Важно: Все внешние ресурсы (шрифты, иконки) подгружаются по CDN, поэтому для корректного отображения необходимо интернет-соединение.



🧩 Настройка и кастомизация

Изменение персональных данных

Откройте index.html и найдите соответствующие блоки:



Имя и должность: раздел .profile-header



Биография: .bio-section .bio-card



Опыт работы: блок .timeline внутри .experience



Образование: блок .education



Навыки: измените список .skill-tag



Статистика: значения в .stats-flex



Контакты: замените href и текст внутри .contact-links



Отзыв: текст и автор внутри .testimonial-card



Изменение цветовой схемы

В файле style.css найдите основные переменные (пока не вынесены в :root, но можно легко сделать). Основные цвета:



Акцентный синий: #1f6392 (кнопки, иконки, акценты)



Тёмный текст: #1a2634, #2d3e50



Фоны карточек: white



Фон страницы: #f5f7fc



Для быстрой замены используйте поиск по #1f6392 и замените на свой корпоративный цвет.



📱 Адаптивность

Планшеты (ширина < 950px): грид перестраивается в одну колонку, шапка выравнивается по центру.



Мобильные устройства (ширина < 600px): уменьшены отступы, размер шрифтов, кнопки становятся компактнее. Таймлайн меняет вертикальную структуру.
